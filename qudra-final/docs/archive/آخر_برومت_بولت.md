SECTION 03 — PRODUCT PHILOSOPHY
============================================================

QUDRA means:

"Don't tell us what you know. Show us what you can do."

Arabic:
"بدل أن تقول إنك تعرف — أثبت أنك تستطيع."

Core model:

Problem → Capability → Evidence → Match → Challenge → Outcome → New Evidence

EVIDENCE FIRST is NON-NEGOTIABLE.

- a job board
- a CV builder

B0 focuses on the flows represented by the supplied prototype.

============================================================
SECTION 04 — PROVEN VS CLAIMED
============================================================

This is one of the most important product concepts.

PROVEN:
- solid border
- turquoise treatment
- evidence counter
- weight indicator when applicable

CLAIMED:
- dashed border
- muted treatment
- NO evidence counter

NEVER visually merge Proven and Claimed.
NEVER use Evidence styling for a Claim.
NEVER use Claim styling for Evidence.
NEVER use background color as the only evidence-strength signal.

Color semantics:
- Teal/Turquoise = Proven / Verified / Complete.
- Yellow = Gap / Missing / Attention.
- Red = Real errors / destructive actions ONLY.

Never use red merely because a skill is missing.
