## للفرونت

**`prototype.html` هو التصميم.** افتحه بـ VS Code:

| تدوّر على | مكانه |
|---|---|
| الألوان | كتلة `:root{ }` بأول الملف — ١٧ متغيّر |
| الوضع الداكن | `:root[data-theme="dark"]{ }` تحتها — ٢٥ متغيّر |
| أي مكوّن | كل واحد له كتلة CSS معلّقة بالعربي — ابحث باسمه |
| الحركات | ابحث `@keyframes` |
| الأيقونات | SVG مضمّن، نمط Lucide، سماكة 1.7–2 |

**الخطوط:** من Google Fonts
```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+Arabic:wght@400;500;600;700&family=IBM+Plex+Mono:wght@400;500&display=swap">
```

### أربع قواعد ما بتنكسر

1. **كل زر ≥ 44px** ارتفاعًا
2. **RTL**، وعرض المحتوى الأقصى **992px**
3. **الفيروزي = مُثبت · الأصفر = ناقص · الأحمر = خطأ فقط**
4. **المهارة المُثبتة ≠ المكتوبة يدويًا:**
   - مُثبتة: خلفية فيروزية + حد صلب + **رقم عدّاد**
   - مكتوبة: شفافة + حد **متقطّع** + بلا رقم

   هاي أهم تفصيلة في المنتج كله. لو ضاعت، ضاع اللي بيميّز قُدرة.

### ⚠️ مهم

النموذج **HTML/JS عادي، صفحة واحدة**، والشاشات بتظهر وتختفي بالـJS.
هاي طريقة نموذج **مش طريقة منتج**.

خد منه **الشكل والـCSS**، وابنِ البنية والراوتنغ بـReact/Vue زي ما بدك.

## للباك والداتا

كل شي في **`dev-handoff.md`**: ٩ مجموعات endpoints، ١٢ جدول، والقواعد اللي بتحكم الأرقام.

**أهم ٣ قواعد:**

1. **الـAI يرجّع JSON منظّم مش نص حر.** ومع كل قدرة يستخرجها لازم يرجّع `source_phrase` — الجملة اللي استخرجها منها. الواجهة بتعرضها تحت كل قدرة، وهي جوهر الفكرة.

2. **الأوزان تجمع 100، والمُثبت يجمع الدرجة.** الواجهة بتعرض التفصيل والمجموع مع بعض، فأي تناقض بيبيّن فورًا.

3. **التقادم يُحسب وقت القراءة.** الدليل بيفقد وزنه مع الوقت — نصف العمر لكل نوع موجود في الملف.

**Fixtures للاختبار** في آخر `dev-handoff.md` — لو بنيتوا عليها، الواجهة بتشتغل من أول مرة.
