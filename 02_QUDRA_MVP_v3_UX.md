# قُدرة — MVP v3 + UX + Priorities

## القرار

الـMVP يثبت فرضية واحدة: هل نستطيع تحويل مشكلة حقيقية إلى قدرات ثم
اختيار أشخاص بناءً على Evidence قابل للفهم؟

## Core Journey

**Problem → AI Analysis → Required Capabilities → Evidence Profiles →
Explainable Matching → Skill Gaps → Optional Challenge → Re-match**.

## 1. Home

العنوان: **لديك مشكلة؟ لا تبحث عن مسمى وظيفي. صف المشكلة، ودع قُدرة تحدد
ما تحتاجه ومن يستطيع إثبات قدرته على حلها.** أزرار: حلّل مشكلتي / استكشف
ملفي.

## 2. Problem Input

Textarea: ما الذي تريد إنجازه؟ أسئلة قصيرة عند الحاجة: النتيجة،
المستخدم، المجال، الموعد، الفريق، الميزانية، هل المطلوب MVP.

## 3. Analysis

Progress: فهم المشكلة → تحديد النتيجة → تحديد القيود → استخراج القدرات →
فحص Evidence → بناء المطابقة.

## 4. Required Capabilities

Cards مثل Backend—High، Frontend—Medium، Speech Processing—High،
ML/NLP—High، Testing—Medium. كل Card تعرض سبب الحاجة والأولوية والمهام
المرتبطة.

## 5. Candidate Results

كل بطاقة: الاسم، الدور، Match، Evidence Count، Strengths، Gaps،
Availability، وزر **لماذا هذا الشخص؟**.

## 6. Why This Person?

مثال 91% Match، ثم الأدلة والمهارات والحداثة والصلة والفجوات
وConfidence. لا رقم بلا تفسير.

## 7. Evidence View

Projects / GitHub / Challenges / External Platforms / Outcomes /
Interviews. كل Evidence: المصدر، النوع، المهارة، التاريخ، التحقق،
النتيجة.

## 8. User Profile

Overview، Skills، Evidence، Readiness. مثال: Frontend 91%، Full Stack
68%. Skills المدخلة يدويًا تبقى منفصلة بصريًا عن Evidence-Backed Skills.

## 9. Skill Gap

إذا قال المستخدم: أريد Full Stack، يظهر Current Readiness، Strengths،
Gaps، ثم Roadmap: Learn → Practice → Prove → Re-match.

## 10. Company-side Skill Gap

الشركة ترى Strengths وGaps للمرشح مع تفسير أثر الفجوة على المشروع، مع
احترام الخصوصية.

## 11. MVP P0

4.  Evidence Records.
5.  AI Evidence Analysis.

## 12. P1 بعد MVP

GitHub Integration، GitHub Deep Analysis، External Challenge Profiles،
Practical Challenge، Oral Evidence، Personalized Roadmap، Evidence
Graph، Automatic Re-analysis.

## 13. P2

Company Challenges، Company Profiles، Challenge Verification، Advanced
Capability Graph، Re-match after challenge، Opportunity Readiness.

## 14. P3

Team Composer، Human + AI Composer، Project Workspace، Outcome →
Evidence، Freelance marketplace، Project publishing.

## 15. P4

Project Intelligence، Market Research، Competitor Research، Risk
Analysis، Revenue Signals، UX Workflow generation، Project Brief،
Startup Intelligence.

## 16. UX Principles

1.  Evidence أهم من الكلام.
2.  AI score يجب أن يملك تفسيرًا.
3.  لا نرهق المستخدم بالنماذج.
4.  كل خطوة تنتج بيانات قابلة لإعادة الاستخدام.
5.  Skills المدخلة يدويًا لا تساوي Evidence تلقائيًا.
6.  المستخدم لا يحتاج معرفة كيف يعمل AI.

## 17. نتجنب في MVP

Marketplace كامل، Social Feed، Payments، Company Challenge Management،
Market Research الكامل، Revenue Prediction، نموذج AI خاص، عشرات
integrations، مقابلات متقدمة، Workspace متقدم.

## 18. Demo

الشركة تكتب مشكلة → AI يحللها → تظهر القدرات → تظهر 5 ملفات → نفتح
Evidence → Why this person → Skill Gap → Challenge → Evidence Added →
Match يتغير.
